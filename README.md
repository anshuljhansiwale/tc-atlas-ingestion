# Teamcenter → Atlas Ingestion (v1)

Ingest IGES files and JSON metadata from Teamcenter, store IGES on a **local filesystem**, and upsert metadata into **MongoDB Atlas**. Embeddings are generated by **Atlas Automated Embedding (Voyage)** — the app only writes `embedding_text`.

```
Teamcenter (mock | REST)
    → IGES on CAD_ROOT (local / NFS)
    → build embedding_text from metadata
    → upsert into Atlas
    → Atlas autoEmbed (Voyage) indexes embedding_text
```

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
```

### Dry-run (no MongoDB required)

```bash
ingest run --dry-run
```

### Full run against Atlas

1. Set `MONGODB_URI` in `.env`.
2. In Atlas, enable Automated Embedding and add a Voyage API key for the project.
3. Create a Vector Search index from [`atlas/vector_index.json`](atlas/vector_index.json) (`autoEmbed` on `embedding_text`, model `voyage-4`). Keep `VOYAGE_MODEL` in sync with that index.
4. Keep `TC_MODE=mock` until Teamcenter REST is wired.

```bash
ingest run
ingest search "aluminum mounting bracket"
```

Search sends the query **string** to `$vectorSearch`; Atlas embeds it with Voyage at query time. No client-side vectors.

## Layout

| Path | Role |
|---|---|
| `src/ingestion/pipeline.py` | Orchestration |
| `src/ingestion/teamcenter/` | `mock` + `rest` clients |
| `src/ingestion/storage.py` | Local IGES writer |
| `src/ingestion/embeddings.py` | Builds `embedding_text` only |
| `src/ingestion/mongo.py` | Atlas upsert + text `$vectorSearch` |
| `atlas/vector_index.json` | `autoEmbed` (Voyage) index definition |

## Configuration

See [`.env.example`](.env.example):

- `CAD_ROOT` — IGES directory
- `TC_MODE=mock|rest`
- `MONGODB_URI` / `MONGODB_DB` / `MONGODB_COLLECTION`
- `VECTOR_INDEX_NAME` — must match the Atlas index name
- `VOYAGE_MODEL` — e.g. `voyage-4` (must match the index `model`)

## Teamcenter REST

Wire real endpoints in `src/ingestion/teamcenter/rest.py`, then set `TC_MODE=rest`.
